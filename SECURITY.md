# Security Policy

## Supported Versions

| Version | Status |
|---------|--------|
| Latest  | ✓ Supported |
| Older   | End of life |

## Reporting a Vulnerability

Please email security@boozeleegov.com or use GitHub Security Advisory.

## Response Time

We aim to respond to security reports within 48 hours.

## Security Scanning

This repository has:
- Secret scanning enabled
- Dependabot monitoring enabled
- Push protection active
